# 永續合約 Avellaneda 離線模擬器

沿用專案的 `AvellanedaEngine`、`quote_proposal`、`GammaController` 和校準器，以 `PaperBroker` 代替真實下單。模擬單向、1 倍槓桿的 USDT 線性永續合約，不載入交易所 connector、不讀 API key，也不會連接 Gate 下單。

預設本金 100 USDT、持倉上限 40 USDT、策略預算 50 USDT、每筆 10 USDT，保留 5 USDT，虧損達 1 USDT 時停止減倉。最低全價差 0.04%。Maker 0.02%、Taker 0.05%、反傭 60% 使用你提供的費率假設。

## 啟動

在此分支的專案根目錄，用 Python 3.10 以上執行：

```bash
python -m pip install -r tools/requirements-avellaneda-simulator.txt
python tools/avellaneda_perpetual_simulator.py
```

瀏覽器開啟 <http://127.0.0.1:8765>；若埠已使用，可加 `--port 8766`。不需要編譯 Hummingbot、安裝完整交易所依賴或 Docker。這是只綁定本機的開發介面；按 Ctrl+C 關閉。

## 圖表與比較

左側可改本金、上限、每筆金額、預算、交易期和隨機種子；展開「費用與成交假設」可改排隊、延遲、反傭付款時間、波動與資金費率。每次執行重新校準，不沿用不符合新設定的舊 gamma。

同一行情和假設穿價量供三種策略比較：

| 模式 | gamma |
|---|---|
| 固定 gamma = 1 | 觀察原固定設定的小額庫存偏移 |
| 校準後固定 gamma | 前置校準取得 γ₀，交易期保持固定 |
| 自適應 gamma | 同一 γ₀，沿用庫存、波動調整、平滑和上下限 |

圖表顯示現金損益、持倉和 gamma；可選一種策略查看中間價、實際生效的模擬掛單與成交。買單/買入為綠色，賣單/賣出為橙色，市價成交另有外框。圖例可隱藏比較曲線；點擊圖表、移動時間軸或播放，可查看當時權益、庫存、gamma 和成交。

結束結果含手續費、已入帳/待入帳反傭、資金費、回撤、最大持倉、30 秒 markout、撤單期間成交、拒單與停止原因。成交表顯示目前時間前最近 30 筆；CSV 匯出所選策略全部成交，JSON 包含三種策略、帳務與設定。

## 行情來源

**合成行情**：固定種子產生 BTC 類似價格路徑；至少 900 秒連續校準後才開始交易，校準期不成交、不計收益。可選震盪、上漲、下跌或中途下跌 2.5%。預設每秒 log-return 標準差 0.75 bps，交易期 1,800 秒，種子 42；這些是示範參數，沒有宣稱貼合 Gate 的價格分布。

**Gate 行情回放**：使用既有 `gate_btc_capture_20260930.csv`，涵蓋 2026/09/30 台北 13:06:39–13:32:13 的最佳買賣價。檔案沒有成交和深度資料。校準後才模擬，且有約 306 秒行情缺口：圖表標灰、不插值、不補成交，過期時撤單，復原後重新暖機。可交易秒數受檔案長度限制，穿價量與排隊仍是假設。

三種策略共用價格路徑及穿價量，沒有各自抽市場隨機數。更換種子改變合成路徑和穿價量；回放模式改種子只改假設穿價量。

## 成交與時間假設

1. 委託先註冊在共用引擎的生命週期，經送單延遲才啟用；到達時跨對手價則 post-only 拒單，不自動改成 taker。
2. 只有**嚴格穿價**才嘗試成交：買單高於後續最佳賣價，或賣單低於後續最佳買價。僅碰價不成交。這是近似模型，不能由最佳買賣價確定真實成交。
3. 每個觀察點、每邊假設穿價量均勻抽 1 到設定上限張；先消耗排隊量，再填訂單，可部分成交。新委託重新排隊。範例每張 0.0001 BTC，取自已採集規則，沒有即時更新規格。
4. 撤單回覆前仍可成交。成交事件與持倉可見時間分開，沿用引擎的對帳等待、撤單和超時保護。
5. 事件在排定時間後第一個觀察點處理，沒有毫秒行情。缺口不累積穿價量、不補成交或缺失資金費結算。
6. `CLOSE` 為 reduce-only，不能跨零變成反向新倉。停止時先撤單、等待回覆、確認模擬持倉，再由引擎市價減倉；使用最佳對手價加設定滑價並扣 taker 費。結束後最多延續 60 秒，以凍結最後行情完成這個合成平倉階段。

上限限制新報價數量，價格和延遲仍可能使名目持倉短暫超標；引擎下一次觀察到時停止減倉。停止虧損不是最終虧損保證，撤單和平倉期間的風險、費用仍會計入。

沒有強平、ADL、保險基金、風險級距、斷線或完整交易所異常模型，不能據此估算高槓桿清算風險。

## 帳務與反傭

線性合約採加權平均開倉價。平倉才將交易損益轉入錢包；未平倉損益為 `(中間價 − 均價) × 有正負號的 BTC 持倉`。

```text
錢包 = 本金 + 已實現交易損益 − 原始手續費 + 已入帳反傭 + 資金費收支
現金權益 = 錢包 + 未實現損益
現金損益 = 現金權益 − 本金
含待付反傭損益 = 現金損益 + 待入帳反傭
```

每次成交先扣原始 maker/taker 費，再記錄 60% 的待入帳反傭，到設定延遲後才轉入錢包，避免重複折扣或提前拿反傭下單。預設延遲 3,600 秒是測試假設，沒有確認 Gate 實際付款時間。含待付損益假設反傭最後全部支付，現金損益只包含已收到部分。

正的 8 小時資金費率代表多倉支付、空倉收取；只在有行情的 UTC 00:00、08:00、16:00 按當時持倉結算，不按秒攤提、不補缺口結算。預設費率 0。

`markout` 為成交方向乘「後續中間價 − 成交價」乘數量，不是已實現損益。30 秒均值只用觀測延遲不超過 10 秒的樣本，未到時間者不填 0，可用來觀察逆向選擇。

## 匯出可離線開啟的互動報告

```bash
python tools/avellaneda_perpetual_simulator.py \
  --export examples/my_simulation.html --json examples/my_simulation.json

python tools/avellaneda_perpetual_simulator.py \
  --source capture --export examples/my_replay.html
```

HTML 自帶結果，不使用 CDN；雙擊即可查看、播放、切換曲線及下載 JSON/CSV。重新計算參數需啟動 Python。輸出不覆蓋既有檔案。CLI 可加 `--scenario downtrend --seed 43 --duration 3600`，或 `--settings settings.json` 載入與 API 相同的參數格式。未指定匯出時在網頁設定參數。

專案附有已產生的[合成行情互動報告](../examples/avellaneda_perpetual_validation/simulation_demo_20260930.html)與[Gate 行情回放報告](../examples/avellaneda_perpetual_validation/simulation_replay_20260930.html)。下載 HTML 後可直接離線開啟。預設合成示例的三模式現金損益分別約 -0.109381、-0.126276、-0.122357 USDT；待付反傭分別約 0.072715、0.074710、0.074710 USDT。這是特定假設和種子的模擬，不是交易所收益或期望收益估計。

## 掛單與 API 保護

共用正式策略的 request guard。每 5 秒檢查報價，價格、剩餘數量和開平倉方向相同
就保留掛單，最多 30 秒；部分成交、對帳、行情過期或風控仍可立即撤單。
新委託與撤單的紙上送出嘗試納入每秒及滾動 24 小時計數。
畫面時間軸下方可查看計數與冷卻；結束比較表新增總請求、保留掛單與 429 次數。

展開「掛單與 API 保護」可調整檢查間隔、最長掛單時間與每日預算。
預設 6 次/秒，其中 2 次供撤單和緊急減倉；每日 50,000 次，在總計數達 49,000 次後
停止新報價、取消委託並減倉。每日安全額度是保留容量，不是禁止緊急操作的硬上限。
紙上計數留在記憶體，實盤版本才保存至 logs 並使用檔案鎖。

「模擬 429」預設 0，表示關閉。設為 30 會在第一筆紙上請求 30 秒後的首次一般
下單嘗試注入一次 HTTP 429；三種策略各自觸發，送出嘗試仍計數。
「模擬冷卻」控制 Retry-After 秒數，另外加正式 guard 的 0.25 秒緩衝。
例如交易期 300 秒、30 秒後觸發、10 秒冷卻，可看到暫停新報價、撤掉舊單和恢復報價。
每日預算設 100、保留 10、交易期 600 秒，可測試額度停機與減倉。
實際恢復時間受行情觀察間隔、撤單及持倉回報延遲影響；持倉歸零沒有時間保證。

模擬沒有真的呼叫 API，也沒有反映同帳戶的其他程序、網路故障或未知交易所限流。
完整實盤政策及 logs 保存方法見 [策略文件](avellaneda_perpetual.md#api-請求與冷卻保護)。
